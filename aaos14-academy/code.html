Three views of the same feature — reading vehicle speed and setting the HVAC temperature: from a Kotlin app, through the AIDL contract, down to a C++ VHAL implementation in the AOSP source tree. Click any numbered line to read its explanation.

⏱ 30 min🎯 Intermediate → Advanced📦 android-14.0.0 · VHAL AIDL V2

5.1Overview

① App (Kotlin)

Connect to Car, subscribe to PERF_VEHICLE_SPEED, write HVAC_TEMPERATURE_SET with config checks. The HVAC part requires a privileged app.

② Contract (AIDL)

IVehicle, IVehicleCallback and the key parcelables. You don't edit these files — read them to understand the contract.

③ VHAL (C++)

An OemVehicleHardware class implementing IVehicleHardware, wired to CAN via SocketCAN; plus build, VINTF and SEPolicy files.

5.3Checklist: adding a new OEM property

Say you need a “seat massage mode” that is not in the standard property list:

#TaskWhere
1Check the standard properties first (SEAT_*) — prefer standard properties so third-party apps can use them.hardware/interfaces/automotive/vehicle/aidl_property
2Define a vendor ID: 0x0101 | VehiclePropertyGroup::VENDOR | VehicleArea::SEAT | VehiclePropertyType::INT32.OEM header
3Add a VehiclePropConfig (access, changeMode, areaConfigs) to getAllPropertyConfigs().OemVehicleHardware.cpp
4Add CAN encode/decode branches in setValues and the RX thread.OemVehicleHardware.cpp
5Assign read/write permissions to the vendor property (by default android.car.permission.CAR_VENDOR_EXTENSION, or customize via SUPPORT_CUSTOMIZE_VENDOR_PERMISSION).VHAL config
6Access it from a system app via CarPropertyManager using the numeric ID.OEM app
7Write hardware unit tests (gtest) and run the relevant VTS/CTS suites.test/

Quick try on the emulator

The AAOS emulator uses FakeVehicleHardware. You can read/write properties with the VHAL's dumpsys commands:

adb shell dumpsys android.hardware.automotive.vehicle.IVehicle/default --set 0x15600503 -a 1 -f 24.0
adb shell dumpsys android.hardware.automotive.vehicle.IVehicle/default --get 0x15600503 -a 1
or through CarService: adb shell cmd car_service get-property-value 0x15600503 1
